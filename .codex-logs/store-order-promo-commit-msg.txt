store/order.php에도 프로모 상품 기능 연동

logistics/order_new.php에만 프로모션 주문 섹션을 추가했으나, 실제 점포 직원이
사용하는 화면은 별도 모듈인 store/order.php였음(이미지/바코드/카테고리탭/임시저장
등 더 풍부한 UI). 이 화면에도 동일 기능을 추가.

- 프로모션(활성+재고>0) LOT 목록 조회 후 상품 테이블 최상단에 강조 행으로 노출
  (기존 .product-row/.qty-input 클래스와 data-* 속성을 그대로 재사용해
  검색/정렬/장바구니합계/임시저장 JS를 별도 수정 없이 그대로 활용)
- 주문 제출 시 promotion_id[] 배열을 product_id[]/quantity[]/order_unit[]와
  병렬로 전달, lc_order_items.promotion_id에 저장
- 재고 검증을 상품+단위 기준 공유 풀 방식으로 변경(프로모션 행 + 일반 행에
  같은 상품이 나뉘어 있어도 합산 재고를 초과하지 않도록)
- 프로모션 지정 항목은 등록된 할인가를 미리보기 단가로 사용(최종 확정 단가는
  기존과 동일하게 접수 직후 lc_allocate_order_stock()이 LOT 기준으로 재계산)
- 백엔드(lc_allocate_order_stock/lc_ship_promo_lot)는 이미 공용 함수라 수정 불필요
