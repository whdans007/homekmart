# 가격표 시스템 배포 전 테스트 체크리스트

## 📋 기본 기능 테스트

### 1. 다국어 기능 테스트
- [ ] 한국어 → 영어 전환 시 모든 텍스트가 정상적으로 변경되는지 확인
- [ ] 영어 → 한국어 전환 시 모든 텍스트가 정상적으로 변경되는지 확인
- [ ] 가격표 출력 화면에서 다국어가 정상적으로 표시되는지 확인
- [ ] JavaScript 알림 메시지들이 다국어로 표시되는지 확인

### 2. 화폐단위 제거 확인
- [ ] 가격표 출력에서 "원" 또는 "KRW"가 표시되지 않는지 확인
- [ ] 가격은 숫자만 표시되고 있는지 확인
- [ ] 모든 가격 표시 위치에서 화폐단위가 제거되었는지 확인

### 3. 가격표 프로젝트 관리
- [ ] 새 프로젝트 생성이 정상적으로 작동하는지 확인
- [ ] 기존 프로젝트 편집이 정상적으로 작동하는지 확인
- [ ] 프로젝트 삭제가 정상적으로 작동하는지 확인
- [ ] 프로젝트 목록 조회가 정상적으로 작동하는지 확인

### 4. 상품 검색 및 추가
- [ ] 바코드 스캔 기능이 정상적으로 작동하는지 확인
- [ ] 상품명으로 검색이 정상적으로 작동하는지 확인
- [ ] SKU로 검색이 정상적으로 작동하는지 확인
- [ ] 검색 결과에서 상품 선택이 정상적으로 작동하는지 확인

### 5. 가격표 출력
- [ ] 프로젝트에서 가격표 출력이 정상적으로 작동하는지 확인
- [ ] 기존 방식의 가격표 출력이 여전히 정상 작동하는지 확인
- [ ] 인쇄 미리보기가 정상적으로 표시되는지 확인

## 🔐 권한 테스트

### 1. 권한별 접근 테스트
- [ ] `super_admin` 권한: 모든 기능에 접근 가능한지 확인
- [ ] `admin` 권한: 가격표 관리 기능에 접근 가능한지 확인
- [ ] `product_management` 권한이 없는 사용자: 접근 차단되는지 확인
- [ ] 로그인하지 않은 사용자: 접근 차단되는지 확인

### 2. 점포별 데이터 분리
- [ ] 각 점포는 자신의 프로젝트만 볼 수 있는지 확인
- [ ] 다른 점포의 프로젝트에 접근할 수 없는지 확인
- [ ] 점포별로 상품 데이터가 올바르게 필터링되는지 확인
