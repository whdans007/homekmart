## ✅ Step 3: API 개발 (100% - 완료)

### 완료된 API

#### 3.1 인증 API ✅ (3개)
- ✅ `POST /api/auth/register` - 회원가입 (JWT 토큰 반환)
- ✅ `POST /api/auth/login` - 로그인 (JWT 인증)
- ✅ `GET /api/auth/profile` - 프로필 조회 (인증 필요)

#### 3.2 상품 API ✅ (2개)
- ✅ `GET /api/products` - 상품 목록 (페이지네이션, 검색, 필터)
- ✅ `GET /api/products/detail` - 상품 상세

#### 3.3 주소 관리 API ✅ (5개)
- ✅ `GET /api/addresses` - 내 주소 목록
- ✅ `POST /api/addresses` - 주소 추가
- ✅ `PUT /api/addresses` - 주소 수정
- ✅ `DELETE /api/addresses` - 주소 삭제 (비활성화)
- ✅ `POST /api/addresses/set-default` - 기본 주소 설정

#### 3.4 장바구니 API ✅ (4개)
- ✅ `GET /api/cart` - 장바구니 조회 (재고 및 합계 포함)
- ✅ `POST /api/cart` - 장바구니 추가 (재고 검증, 중복 처리)
- ✅ `PUT /api/cart` - 수량 변경 (재고 검증)
- ✅ `DELETE /api/cart` - 항목 삭제

#### 3.5 주문 API ✅ (5개)
- ✅ `POST /api/orders` - 주문 생성
  - 장바구니 검증 및 재고 차감
  - 배송비 자동 계산 (구역 기반)
  - 포인트 사용 및 차감
  - 주문 번호 자동 생성 (DO-YYYYMMDD-XXXXX)
  - 배송 추적 초기화
  - 트랜잭션 처리
- ✅ `GET /api/orders` - 주문 목록 (상태 필터, 페이지네이션)
- ✅ `GET /api/orders/detail` - 주문 상세 (상품, 주소, 추적 포함)
- ✅ `POST /api/orders/cancel` - 주문 취소 (재고 복구, 포인트 복구)
- ✅ `GET /api/orders/tracking` - 배달 추적 이력

#### 3.6 배송 구역 API ✅ (3개)
- ✅ `GET /api/delivery-zones` - 배송 가능 구역 조회 (도시/주 필터)
- ✅ `POST /api/delivery-zones/check` - 배송 가능 여부 확인 (서비스 시간 포함)
- ✅ `POST /api/delivery-zones/calculate-fee` - 배송비 계산 (무료 배송 적용)
