# 모바일앱개발준비 - 고객 프로필 정보 확장 구현 계획

## 📋 현재 상황 분석

### ✅ 기존 데이터베이스 구조
- **`customers` 테이블**: 기본 정보만 존재 (이메일, 비밀번호, 이름, phone 등)
- **`shipping_addresses` 테이블**: 배송지 관리용으로 별도 존재
- **`stores` 테이블**: 점포 정보 관리

### ❌ 부족한 기능
- 고객의 기본 주소 정보 없음
- 이용점포 정보 없음
- 구글맵 연동 대비 좌표 필드 없음
- 고객 관리 UI 미구현

## 🎯 1단계: 데이터베이스 스키마 수정

### customers 테이블에 추가할 컬럼

```sql
-- 주소 정보
ALTER TABLE customers ADD COLUMN address_line1 VARCHAR(255) DEFAULT NULL COMMENT '기본 주소';
ALTER TABLE customers ADD COLUMN address_line2 VARCHAR(255) DEFAULT NULL COMMENT '상세 주소';
ALTER TABLE customers ADD COLUMN city VARCHAR(100) DEFAULT NULL COMMENT '시/도';
ALTER TABLE customers ADD COLUMN district VARCHAR(100) DEFAULT NULL COMMENT '구/군';
ALTER TABLE customers ADD COLUMN postal_code VARCHAR(20) DEFAULT NULL COMMENT '우편번호';

-- 구글맵 연동 대비 좌표
ALTER TABLE customers ADD COLUMN latitude DECIMAL(10,8) DEFAULT NULL COMMENT '위도';
ALTER TABLE customers ADD COLUMN longitude DECIMAL(11,8) DEFAULT NULL COMMENT '경도';

-- 이용점포
ALTER TABLE customers ADD COLUMN preferred_store_id INT(11) DEFAULT NULL COMMENT '선호 이용 점포';
ALTER TABLE customers ADD INDEX idx_preferred_store (preferred_store_id);
ALTER TABLE customers ADD FOREIGN KEY (preferred_store_id) REFERENCES stores(id) ON DELETE SET NULL;
```

### 필드 설명

| 컬럼명 | 타입 | 용도 |
|--------|------|------|
| `address_line1` | VARCHAR(255) | 기본 주소 (도로명 또는 지번) |
| `address_line2` | VARCHAR(255) | 상세 주소 (동/호수) |
| `city` | VARCHAR(100) | 시/도 (서울특별시, 경기도 등) |
| `district` | VARCHAR(100) | 구/군 (강남구, 성남시 등) |
| `postal_code` | VARCHAR(20) | 우편번호 |
| `latitude` | DECIMAL(10,8) | 위도 (구글맵 API 연동용) |
| `longitude` | DECIMAL(11,8) | 경도 (구글맵 API 연동용) |
| `preferred_store_id` | INT(11) | 선호 이용 점포 (stores.id 외래키) |

### 향후 구현 예정 (Phase 2)

#### 4-1. 구글맵 API 연동
```javascript
// 주소 입력 시 자동 좌표 변환
function geocodeAddress(address) {
    const geocoder = new google.maps.Geocoder();
    geocoder.geocode({ 'address': address }, function(results, status) {
        if (status === 'OK') {
            const location = results[0].geometry.location;
            document.getElementById('latitude').value = location.lat();
            document.getElementById('longitude').value = location.lng();
        }
    });
}
```

#### 4-2. 지도 표시 기능
- 고객 정보 페이지에 구글맵 표시
- 고객 위치 마커 표시
- 가까운 점포 정보 표시

#### 4-3. 거리 계산 기능
```php
// 두 좌표 간 거리 계산 (Haversine formula)
function calculateDistance($lat1, $lon1, $lat2, $lon2) {
    $earthRadius = 6371; // km
    $dLat = deg2rad($lat2 - $lat1);
    $dLon = deg2rad($lon2 - $lon1);

    $a = sin($dLat/2) * sin($dLat/2) +
         cos(deg2rad($lat1)) * cos(deg2rad($lat2)) *
         sin($dLon/2) * sin($dLon/2);
    $c = 2 * atan2(sqrt($a), sqrt(1-$a));

    return $earthRadius * $c;
}
```

#### 4-4. 활용 방안
- 고객-점포 간 거리 계산
- 가장 가까운 점포 자동 추천
- 배송 가능 지역 판단
- 점포별 고객 분포 지도 시각화

## 🔧 기술적 고려사항

### 데이터베이스
- **인코딩**: UTF-8 (한글 주소 지원)
- **좌표 정밀도**: 위도 DECIMAL(10,8), 경도 DECIMAL(11,8) (약 1cm 정밀도)
- **외래키**: ON DELETE SET NULL (점포 삭제 시 고객 정보는 유지)

### 보안
- 주소 정보는 민감 정보로 취급
- 고객 관리 권한 필수
- 개인정보 보호법 준수

### 성능
- preferred_store_id에 인덱스 추가 (조회 성능 향상)
- 검색 시 FULLTEXT 인덱스 고려 (대용량 데이터 대비)

### 호환성
- 기존 shipping_addresses 테이블과 독립적 운영
- customers 테이블 확장으로 기존 기능 영향 없음
