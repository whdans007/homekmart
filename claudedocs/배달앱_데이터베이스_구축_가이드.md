## 📋 개요

필리핀 배달 쇼핑몰 앱을 위한 데이터베이스 테이블을 생성하는 가이드입니다.

### 생성될 테이블
1. **delivery_addresses** - 필리핀 주소 관리 (바랑가이, 랜드마크)
2. **delivery_zones** - 배달 지역 및 배달비 설정
3. **delivery_orders** - COD 중심 주문 관리
4. **delivery_order_items** - 주문 상품 상세
5. **delivery_tracking** - 실시간 배달 추적
6. **shopping_cart** - 장바구니
7. **wishlists** - 위시리스트
8. **delivery_settings** - 앱 전체 배달 설정

### 수정될 테이블
- **users** - 구글 로그인 지원 컬럼 추가

## 📊 생성된 테이블 구조

### delivery_addresses (배달 주소)
```
주요 컬럼:
- house_number, street, barangay (필리핀 주소)
- city, province, postal_code
- landmark (랜드마크 - 필리핀에서 중요!)
- latitude, longitude (GPS 좌표)
- is_default (기본 주소 여부)
```

### delivery_zones (배달 지역)
```
주요 컬럼:
- zone_name, city, province (지역 정보)
- delivery_fee (배달비 PHP)
- free_delivery_threshold (무료 배달 최소 금액)
- estimated_delivery_time (예상 배달 시간)
- service_start_time, service_end_time
```

### delivery_orders (배달 주문)
```
주요 컬럼:
- order_number (주문 번호)
- subtotal, delivery_fee, total_amount (금액)
- payment_method (cod, gcash, paymaya, online)
- order_status (pending → confirmed → preparing → delivered)
- cod_amount, change_amount (COD 거스름돈)
```

### delivery_order_items (주문 상품)
```
주요 컬럼:
- product_name, product_price (주문 시점 스냅샷)
- quantity, subtotal
- product_options (JSON 형태 옵션)
```

### delivery_tracking (배달 추적)
```
주요 컬럼:
- status (상태)
- status_message (메시지)
- latitude, longitude (배달원 현재 위치)
- timestamp (상태 변경 시간)
```

## ⚠️ 주의사항

### 1. 외래키 제약조건
- users, stores, products 테이블과 연결되어 있음
- 해당 테이블이 없으면 오류 발생 가능
- `IF NOT EXISTS` 사용으로 중복 생성 방지

### 2. 데이터 타입
- 금액: `DECIMAL(10, 2)` - PHP Peso
- 좌표: `DECIMAL(10, 8)` (위도), `DECIMAL(11, 8)` (경도)
- 날짜: `TIMESTAMP` - 자동 타임존 처리

### 3. 문자셋
- `utf8mb4` - 이모지 포함 모든 문자 지원
- 필리핀 지명, 영어, 한국어 모두 지원

### 4. 롤백
문제 발생 시:
```sql
-- 테이블 삭제
DROP TABLE IF EXISTS delivery_tracking;
DROP TABLE IF EXISTS delivery_order_items;
DROP TABLE IF EXISTS delivery_orders;
DROP TABLE IF EXISTS delivery_zones;
DROP TABLE IF EXISTS delivery_addresses;
DROP TABLE IF EXISTS shopping_cart;
DROP TABLE IF EXISTS wishlists;
DROP TABLE IF EXISTS delivery_settings;
```

## 🆘 문제 해결

### 오류: "Table 'users' doesn't exist"
→ users 테이블이 없습니다. 기존 데이터베이스 구조 확인 필요

### 오류: "Duplicate column name 'google_id'"
→ 이미 실행됨. users 테이블 확인:
```sql
DESCRIBE users;
```

### 오류: "Foreign key constraint fails"
→ 외래키 참조 테이블 확인 (users, stores, products)
