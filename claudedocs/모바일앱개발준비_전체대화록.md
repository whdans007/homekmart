## 📝 대화 요약

### 초기 질문: 고객 프로필 정보 확인
**사용자 질문**: "고객 주소, 이용점포를 관리할 수 있는 프로필 정보는 없어?"

**분석 결과**:
현재 HOME K MART 시스템의 고객 데이터베이스 구조를 조사한 결과, 다음과 같은 상황을 확인했습니다:

#### ✅ 존재하는 테이블

1. **`customers` 테이블** (온라인 쇼핑몰 고객용)
   - 위치: `infrastructure/database/migrations/001_create_shop_tables.sql`
   - 저장 정보:
     - 기본 정보: `id`, `email`, `password`, `name`
     - 연락처: `phone`
     - 개인정보: `birth_date`, `gender`
     - 상태 관리: `status` (active/inactive/suspended)
     - 이메일 인증: `email_verified`, `email_verified_at`
     - 마케팅 동의: `marketing_agree`
     - 로그인 추적: `last_login_at`
     - 타임스탬프: `created_at`, `updated_at`

   **❌ 부족한 필드:**
   - 주소 정보 없음
   - 이용점포 정보 없음
   - 위치 좌표 없음

2. **`shipping_addresses` 테이블** (배송지 관리용)
   - 배송지 주소 정보 저장
   - 필드:
     - 수령인 정보: `recipient_name`, `recipient_phone`
     - 주소: `address_line1`, `address_line2`, `city`, `state`, `postal_code`, `country`
     - 기본 배송지: `is_default`
     - 연결: `customer_id` (customers 테이블), `order_id` (주문별 배송지)
   - **특징**: 배송용으로만 사용, 고객 기본 프로필과 분리됨

3. **`wholesale_customers` 테이블** (도매 거래처용)
   - 도매 거래처 정보 관리
   - 필드: `name`, `phone`, `address`, `memo`
   - **특징**: 일반 고객(`customers`)과 완전히 별도 테이블

4. **`stores` 테이블** (점포 정보)
   - 점포 기본 정보: `id`, `name`, `address`, `phone`, `manager`
   - 상태: `is_active`
   - **활용 가능**: 고객의 이용점포 연결을 위한 외래키로 사용 가능

#### ❌ 발견된 문제점

1. **고객 기본 주소 정보 없음**
   - `customers` 테이블에 주소 필드 부재
   - 배송지(`shipping_addresses`)만 있어 고객 기본 거주지 정보 부족

2. **이용점포 정보 없음**
   - 고객이 주로 이용하는 점포 정보 없음
   - 점포별 고객 관리 불가능

3. **위치 기반 서비스 준비 부족**
   - 위도/경도 정보 없음
   - 구글맵 연동 불가능
   - 점포-고객 거리 계산 불가

4. **고객 관리 UI 미구현**
   - 도매 거래처 관리(`wholesale_customer_management.php`)는 구현됨
   - 일반 고객 관리 페이지 없음
   - 고객 정보 조회/수정 기능 없음

### 1단계: 데이터베이스 스키마 확장

#### customers 테이블 추가 컬럼

```sql
-- 주소 정보 (필리핀 주소 체계에 맞춤)
ALTER TABLE customers ADD COLUMN address TEXT DEFAULT NULL COMMENT '전체 주소 (Philippine address format)';

-- 구글맵 연동 대비 좌표
ALTER TABLE customers ADD COLUMN latitude DECIMAL(10,8) DEFAULT NULL COMMENT '위도';
ALTER TABLE customers ADD COLUMN longitude DECIMAL(11,8) DEFAULT NULL COMMENT '경도';

-- 이용점포
ALTER TABLE customers ADD COLUMN preferred_store_id INT(11) DEFAULT NULL COMMENT '선호 이용 점포';
ALTER TABLE customers ADD INDEX idx_preferred_store (preferred_store_id);
ALTER TABLE customers ADD FOREIGN KEY (preferred_store_id) REFERENCES stores(id) ON DELETE SET NULL;
```

#### 필드 설명 및 설계 근거

| 컬럼명 | 타입 | NULL | 용도 | 설계 근거 |
|--------|------|------|------|----------|
| `address` | TEXT | YES | 전체 주소 | 필리핀 주소 체계 - 한 곳에 전체 주소 입력 |
| `latitude` | DECIMAL(10,8) | YES | 위도 | 소수점 8자리 = 약 1cm 정밀도 |
| `longitude` | DECIMAL(11,8) | YES | 경도 | 소수점 8자리 = 약 1cm 정밀도 |
| `preferred_store_id` | INT(11) | YES | 선호 이용 점포 | stores.id 외래키 |

**설계 원칙**:
- 모든 필드 NULL 허용: 기존 데이터 호환성 및 점진적 데이터 입력
- UTF-8 인코딩: 영문/필리핀어 주소 완벽 지원
- 필리핀 주소 체계: 시/동/읍/면 구분 없이 TEXT 타입으로 자유 형식 입력
- 외래키 ON DELETE SET NULL: 점포 삭제 시 고객 정보 유지

**SQL 쿼리 예시**:
```sql
SELECT
    c.id,
    c.name,
    c.email,
    c.phone,
    c.address,
    s.name as store_name,
    c.status,
    c.created_at,
    c.last_login_at
FROM customers c
LEFT JOIN stores s ON c.preferred_store_id = s.id
WHERE
    c.status = 'active'
    AND (c.name LIKE ? OR c.email LIKE ? OR c.phone LIKE ? OR c.address LIKE ?)
ORDER BY c.created_at DESC
LIMIT ? OFFSET ?
```

**2. Geocoding (주소 → 좌표 변환)**:
```javascript
function geocodeAddress(address) {
    const geocoder = new google.maps.Geocoder();
    geocoder.geocode({ 'address': address }, function(results, status) {
        if (status === 'OK') {
            const location = results[0].geometry.location;
            document.getElementById('latitude').value = location.lat();
            document.getElementById('longitude').value = location.lng();

            // 지도에 마커 표시
            showMapMarker(location);
        } else {
            alert('주소를 찾을 수 없습니다: ' + status);
        }
    });
}
```

**3. 지도 표시**:
```javascript
let map;
let marker;

function initMap(lat, lng) {
    const position = { lat: lat, lng: lng };

    map = new google.maps.Map(document.getElementById('map'), {
        zoom: 15,
        center: position
    });

    marker = new google.maps.Marker({
        position: position,
        map: map,
        draggable: true
    });

    // 마커 드래그 시 좌표 업데이트
    marker.addListener('dragend', function(event) {
        document.getElementById('latitude').value = event.latLng.lat();
        document.getElementById('longitude').value = event.latLng.lng();
    });
}
```

##### B. 거리 계산 기능

**PHP 함수 (Haversine Formula)**:
```php
/**
 * 두 좌표 간 거리 계산 (Haversine formula)
 * @param float $lat1 시작점 위도
 * @param float $lon1 시작점 경도
 * @param float $lat2 끝점 위도
 * @param float $lon2 끝점 경도
 * @return float 거리 (km)
 */
function calculateDistance($lat1, $lon1, $lat2, $lon2) {
    $earthRadius = 6371; // 지구 반지름 (km)

    $dLat = deg2rad($lat2 - $lat1);
    $dLon = deg2rad($lon2 - $lon1);

    $a = sin($dLat/2) * sin($dLat/2) +
         cos(deg2rad($lat1)) * cos(deg2rad($lat2)) *
         sin($dLon/2) * sin($dLon/2);

    $c = 2 * atan2(sqrt($a), sqrt(1-$a));

    return $earthRadius * $c;
}
```

**활용 예시**:
```php
// 고객 목록에서 가까운 점포 표시
$customer_lat = $customer['latitude'];
$customer_lon = $customer['longitude'];

$stores = getActiveStores(); // 활성 점포 목록
$nearest_store = null;
$min_distance = PHP_FLOAT_MAX;

foreach ($stores as $store) {
    if (!empty($store['latitude']) && !empty($store['longitude'])) {
        $distance = calculateDistance(
            $customer_lat, $customer_lon,
            $store['latitude'], $store['longitude']
        );

        if ($distance < $min_distance) {
            $min_distance = $distance;
            $nearest_store = $store;
        }
    }
}

echo "가장 가까운 점포: {$nearest_store['name']} (거리: " . round($min_distance, 2) . "km)";
```

##### C. 활용 방안

1. **고객-점포 간 거리 계산**
   - 고객 위치 기준 가까운 점포 추천
   - 점포별 고객 분포 분석

2. **배송 가능 지역 판단**
   - 점포별 배송 반경 설정 (예: 5km 이내)

   - 히트맵으로 고객 밀집도 표시

4. **마케팅 활용**
   - 특정 반경 내 고객 타겟팅
   - 지역별 프로모션 대상 선정

## 🔧 기술적 고려사항

### 데이터베이스
- **인코딩**: UTF-8 (utf8mb4) - 한글 주소 완벽 지원
- **좌표 정밀도**: DECIMAL(10,8) / DECIMAL(11,8) - 약 1cm 정밀도
- **외래키**: ON DELETE SET NULL - 점포 삭제 시 고객 정보 유지
- **인덱스**: preferred_store_id - 점포별 조회 성능 향상

### 보안
- **개인정보 보호**: 주소 정보는 민감 정보로 취급
- **권한 관리**: customer_management 권한 필수
- **점포별 접근 제어**: admin은 자기 점포 고객만 조회
- **개인정보 보호법 준수**: 수집/이용 동의, 제3자 제공 등

### 성능
- **인덱스 최적화**: preferred_store_id, status 컬럼 인덱스
- **페이징 처리**: LIMIT/OFFSET으로 대용량 데이터 대비
- **검색 최적화**: LIKE 검색 시 인덱스 활용
- **FULLTEXT 인덱스**: 대용량 데이터 시 고려 (향후)

### 호환성
- **기존 테이블 독립성**: shipping_addresses와 별도 운영
- **하위 호환성**: 기존 customers 데이터 영향 없음
- **NULL 허용**: 점진적 데이터 입력 가능
- **외래키 유연성**: ON DELETE SET NULL로 데이터 보존

### 확장성
- **모바일 앱 대비**: RESTful API 구조로 확장 가능
- **구글맵 연동**: 좌표 필드 사전 준비
- **다국어 지원**: lang_helper.php 활용
- **추가 필드 확장**: 테이블 구조 유연성 확보

## 📋 SQL 마이그레이션 파일 (완성본)

```sql
-- ====================================================================
-- 고객 프로필 확장 마이그레이션 (필리핀 주소 체계)
-- 파일명: add_customer_profile_fields.sql
-- 목적: 모바일 앱 개발을 위한 고객 주소 및 위치 정보 추가
-- 작성일: 2025-10-02
-- 수정일: 2025-10-03 (필리핀 주소 체계 반영)
-- ====================================================================

USE u622428657_homekmart;

-- 1. 주소 정보 컬럼 추가 (필리핀 주소 체계 - TEXT 타입)
ALTER TABLE customers
ADD COLUMN address TEXT DEFAULT NULL COMMENT 'Complete address (Philippine format - free text)' AFTER phone;

-- 2. 위치 좌표 컬럼 추가 (구글맵 연동 대비)
ALTER TABLE customers
ADD COLUMN latitude DECIMAL(10,8) DEFAULT NULL COMMENT 'Latitude (Google Maps API integration)' AFTER address;

ALTER TABLE customers
ADD COLUMN longitude DECIMAL(11,8) DEFAULT NULL COMMENT 'Longitude (Google Maps API integration)' AFTER latitude;

-- 3. 이용점포 컬럼 추가
ALTER TABLE customers
ADD COLUMN preferred_store_id INT(11) DEFAULT NULL COMMENT 'Preferred store ID' AFTER longitude;

-- 4. 인덱스 추가 (성능 최적화)
ALTER TABLE customers
ADD INDEX idx_preferred_store (preferred_store_id);

-- 5. 외래키 제약조건 추가
ALTER TABLE customers
ADD CONSTRAINT fk_customers_store
FOREIGN KEY (preferred_store_id)
REFERENCES stores(id)
ON DELETE SET NULL
ON UPDATE CASCADE;

-- 6. 마이그레이션 완료 확인
SELECT
    'customers 테이블 구조 확인' as message,
    COLUMN_NAME,
    COLUMN_TYPE,
    IS_NULLABLE,
    COLUMN_DEFAULT,
    COLUMN_COMMENT
FROM INFORMATION_SCHEMA.COLUMNS
WHERE TABLE_SCHEMA = 'u622428657_homekmart'
  AND TABLE_NAME = 'customers'
  AND COLUMN_NAME IN (
      'address', 'latitude', 'longitude', 'preferred_store_id'
  )
ORDER BY ORDINAL_POSITION;

-- 마이그레이션 완료
SELECT '✅ customers 테이블 프로필 확장 완료 (Philippine address format)!' as status;
```
