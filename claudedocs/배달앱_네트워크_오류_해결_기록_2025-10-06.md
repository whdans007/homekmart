
## 🎯 근본 원인

**API 응답의 `id` 필드가 문자열 `"23196"`로 반환되는데, Flutter ProductModel은 정수(int)를 기대하여 JSON 파싱 실패**

- API 통신: ✅ 성공 (200 OK)
- 데이터 수신: ✅ 성공 (20개 상품)
- JSON 파싱: ❌ **실패** (타입 불일치)
- 에러 표시: "Network error while fetching products"

---

## 💡 해결 방안

### 방법 1: API 수정 (권장)
**파일**: `api/products/index.php`
**위치**: 71줄 바로 위

**수정 전**:
```php
$products = [];
while ($row = $result->fetch_assoc()) {
    $row['selling_price'] = floatval($row['selling_price']);
    $row['cost_price'] = floatval($row['cost_price']);
    $row['quantity'] = intval($row['quantity']);
    $row['is_active'] = (bool) intval($row['is_active']);
    $products[] = $row;
}
```

**수정 후**:
```php
$products = [];
while ($row = $result->fetch_assoc()) {
    $row['id'] = intval($row['id']);  // ✅ 추가
    $row['selling_price'] = floatval($row['selling_price']);
    $row['cost_price'] = floatval($row['cost_price']);
    $row['quantity'] = intval($row['quantity']);
    $row['is_active'] = (bool) intval($row['is_active']);
    if ($row['category_id']) $row['category_id'] = intval($row['category_id']);  // ✅ 추가
    if ($row['brand_id']) $row['brand_id'] = intval($row['brand_id']);  // ✅ 추가
    $products[] = $row;
}
```

### 방법 2: Flutter 모델 수정 (대안)
**파일**: `lib/data/models/product_model.dart`

Custom JSON converter 추가:
```dart
// Helper function 추가
int _toInt(dynamic value) {
  if (value is int) return value;
  if (value is String) return int.parse(value);
  throw FormatException('Cannot convert $value to int');
}

@JsonSerializable()
class ProductModel {
  @JsonKey(fromJson: _toInt)  // ✅ Custom converter 사용
  final int id;
  // ...
}
```

그 후 `flutter pub run build_runner build` 실행 필요
