🔄 간단한 데이터 백업 가이드

MySQL 연결 오류가 발생했을 때 사용할 수 있는 대체 방법들입니다.

🎯 방법 1: phpMyAdmin 내보내기 (가장 쉬움)

1단계: phpMyAdmin 접속

  • XAMPP Control Panel → MySQL "Admin" 버튼 클릭
  • 또는 브라우저에서 http://localhost/phpmyadmin 접속

2단계: 데이터베이스 선택

  • 좌측 목록에서 min 데이터베이스 클릭
  • 만약 'min' 데이터베이스가 없다면 실제 사용하는 데이터베이스명 확인

3단계: 내보내기 실행

  • 상단 메뉴에서 "내보내기" 탭 클릭
  • "빠른" 방식 선택
  • 형식: "SQL" 선택
  • "실행" 버튼 클릭
  • .sql 파일이 다운로드됨

4단계: 운영 서버용으로 수정

다운로드한 SQL 파일을 텍스트 에디터로 열어서 다음과 같이 수정:

-- 파일 맨 위에 추가 DROP DATABASE IF EXISTS `if0_39723369_min`; CREATE DATABASE IF NOT EXISTS `if0_39723369_min` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci; USE `if0_39723369_min`; SET FOREIGN_KEY_CHECKS = 0; SET AUTOCOMMIT = 0; START TRANSACTION; -- 기존 SQL 내용 그대로 유지 -- 파일 맨 아래에 추가 COMMIT; SET FOREIGN_KEY_CHECKS = 1; SET AUTOCOMMIT = 1;

⚡ 방법 2: 명령줄 도구 (고급)

Windows 명령 프롬프트에서

# XAMPP 사용자 cd C:\xampp\mysql\bin mysqldump -u root -p min > backup.sql # 일반 MySQL 설치 cd "C:\Program Files\MySQL\MySQL Server 8.0\bin" mysqldump -u root -p min > backup.sql

비밀번호를 물어보면 MySQL root 비밀번호 입력 (없으면 그냥 Enter)

🔍 방법 3: 데이터베이스 정보 확인

현재 데이터베이스 상태 확인

phpMyAdmin SQL 탭에서 다음 명령어 실행:

-- 모든 데이터베이스 목록 SHOW DATABASES; -- 현재 데이터베이스의 테이블 목록 SHOW TABLES; -- 특정 테이블의 데이터 개수 확인 SELECT COUNT(*) FROM users; SELECT COUNT(*) FROM products; SELECT COUNT(*) FROM inventory;

💡 추천 순서

  1. 방법 1을 먼저 시도 (가장 쉽고 안전)
  2. phpMyAdmin 내보내기로 .sql 파일 생성
  3. 파일을 수정하여 운영 서버용으로 변환
  4. InfinityFree phpMyAdmin에서 실행

🚀 운영 서버 적용 방법

InfinityFree에서 실행

  1. InfinityFree 제어판 → MySQL → phpMyAdmin 접속
  2. 데이터베이스 if0_39723369_min 선택
  3. SQL 탭 선택
  4. 수정한 SQL 파일 내용 붙여넣기
  5. 실행 버튼 클릭
  6. 성공 메시지 확인

⚠️ 주의사항

  • 백업 작업 전에 현재 데이터베이스 상태를 확인하세요
  • 운영 서버 실행 전에 SQL 파일을 검토하세요
  • 큰 파일의 경우 여러 번에 나누어 실행할 수 있습니다
